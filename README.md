# Multi-Intelligence Assessment App

A comprehensive web application designed to assess different types of human intelligence (Spatial, Musical, etc.). This project features a React frontend powered by Vite and a Node.js Express backend with SQLite for data persistence.

## Features

- **Spatial Assessment**: Engaging tests to evaluate spatial reasoning and visualization skills.
- **Musical Assessment**: Tools to assess musical intelligence and auditory perception.
- **User Authentication**: Secure sign-up/login system for tracking progress.
- **Interactive UI**: Modern, responsive design with interactive components.

## Prerequisites

- **Node.js**: [Download and install Node.js](https://nodejs.org/)
- **npm**: Installed automatically with Node.js.
- **Git**: [Download and install Git](https://git-scm.com/) (Required for GitHub operations).

## Getting Started

1. **Clone the repository** (after uploading to GitHub):
   ```bash
   git clone https://github.com/sushmidha8/MI_Assessment.git
   cd MI_Assessment/multi-intelligence-app
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run the Application**:
   ```bash
   npm run dev
   ```
   *This command runs both the frontend (Vite) and the backend (Node.js) concurrently.*

## Project Structure

- `src/components/`: React components for different assessment modules.
- `backend/`: Express server logic and database configuration.
- `public/`: Static assets and media.
- `package.json`: Project configuration and scripts.
